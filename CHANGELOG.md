# Changelog

All notable changes to this template are documented here. The format follows Keep a Changelog and versions follow Semantic Versioning.

## [Unreleased]

## [0.3.0] - 2026-08-12

### Added

- Deterministic, exact-ID cleanup and forwarding recovery plans with stale-state checks, acknowledgement, and sanitized audit artifacts.
- Discovery-first existing-workspace observability planning, schema-tolerant source assets, and privacy-safe client/Intune evidence.
- GET-only remote-network and Adaptive Access inventory plus narrowly gated creation plans for one new commercial-cloud network and first device link.
- Sanitized Graph contract variations, fail-closed schema-drift tests, conservative sample azd values, Mermaid architecture/lifecycle sources, and Awesome AZD preparation guidance.

### Changed

- Expanded the template contract from infrastructure provisioning to a complete safety-focused POC lifecycle while keeping all optional tenant mutations disabled by default.
- Pinned validation guidance and CI to azd 1.30.0, Pester 5.7.1, and PSScriptAnalyzer 1.25.0.

### Security

- Preserved exact-ID ownership, atomic pending/committed state, unmanaged/reused resources, active certificates, forwarding bypasses, and non-mutating ordinary `azd down` behavior.
- Prevented committed samples and fixtures from containing credentials, private certificate material, or remote-network shared-secret material.

## [0.2.0]

### Added

- Initial safety-focused Global Secure Access Azure and Microsoft Graph template capabilities.
